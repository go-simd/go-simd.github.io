go-simd

Pure-Go SIMD drop-ins for the standard library — base64, base32, hex, utf8, adler32, strconv and the primitives under them, with byte-identical output on plain go build.

CGO_ENABLED=0 go-asmgen-generated amd64 · arm64 · loong64 · riscv64 llvm-mca cycle-modelled 100% coverage honest benchmarks
Documentation GitHub

Each package is a drop-in: the same signatures and byte-identical output (and errors) as the stdlib package it accelerates. The hot loop is real SIMD assembly emitted by go-asmgen for all four 64-bit Go targets and encoded by cmd/asm; the short tail delegates back to the standard library so results match exactly. The numbers are measured and honest — wins, parities, and the cases where SIMD genuinely does not help.

Every kernel is generated by go-asmgen over a shared ABI0 layout (amd64 SSE2/AVX2, arm64 NEON, loong64 LSX/LASX, riscv64 RVV), cycle-modelled with llvm-mca, validated on real AVX2 / native arm64 / QEMU riscv64+loong64, and held at 100% statement coverage as a CI gate. The headline benchmarks come from native CI, never from emulation.
